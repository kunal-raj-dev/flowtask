# FlowTask Quick Capture Extension

A minimal, zero-bloat Manifest V3 browser extension to capture tasks from any webpage directly into FlowTask with one click.

## Installation in Chrome / Edge / Brave

1. Open `chrome://extensions` (or `edge://extensions` in Edge).
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked**.
4. Select the `extension/` directory from this project (`c:\Users\kunal\Desktop\notion\extension`).
5. Pin the FlowTask icon to your browser toolbar!

## Features
- **1-Click Autofill**: Automatically grabs the active page's title and URL.
- **Priority Assignment**: Quickly tag tasks as P1, P2, P3, or P4.
- **Instant Capture**: Automatically routes captured tasks into your FlowTask Inbox.
