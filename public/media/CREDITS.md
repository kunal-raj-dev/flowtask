# FlowTask media credits

## Background artwork

The 48 still scenes in `backgrounds/v1/` were individually created for FlowTask with the built-in OpenAI image generation tool on 16 October 2026. They are original AI-generated artwork, including the photographic-style scenes; they are not downloaded stock photographs. No third-party stock license or CC0 status is asserted. The project uses these generated outputs under the applicable OpenAI terms. There is no external source URL for these original generations.

The complete prompt set and saved source references are recorded in `docs/media-background-sources.json`. The locally served primary WebP files retain their native generation dimensions; 960px and thumbnail variants are delivery derivatives, not separate counted artworks. Native PNG outputs remain in the generation archive on the creation machine; the repository contains production WebP assets.
